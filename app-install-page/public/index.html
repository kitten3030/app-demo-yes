安裝 iOS App

請用 Safari 開啟本頁並點按鈕安裝。手機的 UDID 必須已加入描述檔；第一次安裝後， 到「設定 → 一般 → VPN 與裝置管理」信任開發者才能開啟。

備用：Sideloadly 側載（未簽署 IPA）

手機 UDID 未加入描述檔、或上方安裝失敗時使用。此 IPA 未簽署，不能直接點開安裝， 請下載到電腦，用 Sideloadly 以 Apple ID 簽署並安裝到 iPhone。

下載未簽署 IPA
  1. 在 Windows 安裝 Apple 官網版 iTunes 與 iCloud（不要用 Microsoft Store 版），再安裝 Sideloadly。
  2. 用傳輸線連接 iPhone 與電腦，手機點「信任此電腦」。iOS 16 以上要先到「設定 → 隱私權與安全性 → 開發者模式」開啟並重新開機。
  3. 在電腦上下載本頁的 IPA，拖進 Sideloadly，輸入 Apple ID（建議用專門申請的帳號），按 Start。
  4. 安裝完成後到「設定 → 一般 → VPN 與裝置管理」信任該 Apple ID，再開啟 App。

免費 Apple ID 簽署的 App 效期 7 天，到期需重新側載；同一個 Apple ID 最多同時 3 個側載 App。
